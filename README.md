# 🚀 Mi Portafolio | Luis Eduardo

> 🎨 **Mi primer portafolio profesional** donde demuestro mis habilidades en desarrollo web Full Stack

## 📋 Descripción del Proyecto

¡Bienvenido a mi portafolio personal! 🎉 Este es mi primer proyecto profesional donde muestro todo lo que sé hacer con **HTML, CSS y JavaScript vanilla**. Sin frameworks, sin atajos - puro código web moderno y funcional.

## ✨ Características Principales

### 🎯 **Funcionalidades Interactivas**
- 🌓 **Modo Oscuro/Claro**: Toggle con persistencia en localStorage
- ⌨️ **Efecto Typing**: Animación dinámica de títulos profesionales
- 📱 **Diseño 100% Responsive**: Desktop, tablet y mobile
- 🍔 **Menú Hamburguesa**: Navegación optimizada para móviles
- 🎭 **Animaciones Scroll**: Fade-in elements con IntersectionObserver
- ⬆️ **Scroll-to-Top**: Botón flotante inteligente
- 🧭 **Navegación Activa**: Resaltado automático de sección actual

### 🛠️ **Secciones del Portafolio**
- 👨‍💻 **Hero**: Presentación personal con foto de perfil
- 💪 **Habilidades**: Marquee infinito con logos de tecnologías
- 📁 **Proyectos**: Grid de proyectos con enlaces a GitHub y demo
- 📧 **Contacto**: Formulario funcional con validación en tiempo real
- 🔗 **Footer**: Redes sociales e información de contacto
